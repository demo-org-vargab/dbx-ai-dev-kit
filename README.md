# AI Dev Kit

This repository contains a simple GitHub Actions workflow example for testing a Databricks-based development setup.

## Contents
- GitHub Actions workflow for basic setup and deployment checks
- Example steps for installing the Databricks CLI, Node.js 24, and UV

## Getting Started
1. Review the workflow in `.github/workflows/hello-world.yml`.
2. Configure any required GitHub repository variables and secrets.
3. Push changes to the `main` branch to trigger the workflow.
